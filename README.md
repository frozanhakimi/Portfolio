FROZAN HAKIMI - PERSONAL PORTFOLIO
================================

ABOUT THE PROJECT
-----------------
This is a simple, responsive personal portfolio website created for
Frozan Hakimi using HTML, CSS, and JavaScript.

The website presents personal information, skills, projects, and
contact information in a clean and modern design.

TECHNOLOGIES
------------
- HTML5
- CSS3
- JavaScript

WEBSITE SECTIONS
----------------

1. HOME
   Introduces Frozan Hakimi as a Frontend Developer.
   It also includes a "Say Hello" interactive button.

2. ABOUT ME
   Provides information about my interests, learning journey,
   goals, and experience in web development.

3. SKILLS

   Programming Languages:
   - HTML - 90%
   - CSS - 80%
   - JavaScript - 65%

   Languages:
   - English - 80%
   - Dari - 100%
   - Pashto - 100%

   Computer Skills:
   - Microsoft Word - 90%
   - PowerPoint - 85%
   - Excel - 80%

   The skill percentages start at 0% and increase with an animation
   when the user reaches the Skills section.

4. PROJECTS
   - Calculator
   - Food Order
   - PathFinder

5. CONTACT
   Contains email and GitHub contact information.

FEATURES
--------
- Responsive design for desktop, tablet, and mobile
- Dark and light mode
- Animated skill percentage bars
- Smooth scrolling navigation
- Hover effects
- Interactive "Say Hello" button
- Clean and simple user interface
- Border around the main page

PROJECT FILES
-------------
index.html
    Contains the structure and content of the website.

style.css
    Contains the colors, layout, design, responsive styles,
    cards, borders, and visual effects.

script.js
    Contains the interactive features such as the Hello button,
    theme switching, and animated skill percentages.

README.txt
    Contains information about the project and its structure.

HOW TO RUN
----------
1. Open the project folder.
2. Open index.html in a web browser.
3. You can also use VS Code with Live Server.

RESPONSIVE DESIGN
-----------------
CSS Media Queries are used to make the website responsive.

On smaller screens:
- The navigation adjusts to the screen size.
- Home content changes to a column layout.
- Skill cards become one column.
- Project cards become one column.
